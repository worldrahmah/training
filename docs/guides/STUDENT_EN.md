# Student / Participant usage guide — RC1R10

## Get an account and sign in

Your administrator supplies a registered Participant account. A class code does not create an account. Open /student at the classroom host address provided by your Trainer, using a modern browser on the same trusted LAN. Internet is not required for the application and bundled course assets. Enter your own username/password; never share it. No demo credentials appear on sign-in. Change a temporary password when prompted. If an old installation requires local setup, ask the operator/Admin; do not try to edit files or create a new identity to bypass it.

Use the menu for English/Arabic, light/dark/system appearance and sign-out. Arabic uses right-to-left navigation, but a course keeps its authored language and text. A changed activity-type label does not rename your saved work. Use Tab and Enter for keyboard navigation; Escape closes menus/dialogs. On narrow screens scroll the page/appropriate table and use visible navigation controls. If a control is disabled or missing, your class state or permissions may not allow the action.

## Join and find your class

Select Join class, enter the code given by your Trainer and submit the request. The request stays Pending until an assigned managing Trainer approves; Admin may intervene. Do not assume success means enrollment. Look for the actual status/notification. A rejected or capacity-limited request requires Trainer help. You must use a registered account; an anonymous person cannot enter using only the code. Do not repeatedly submit different usernames or accounts.

Your dashboard lists your enrolled classes, sessions/schedule and progress. Select the intended class, especially if several are active. Withdrawing from a class does not delete your previous responses/history. If you are re-added, existing evidence should remain. Contact Admin/Trainer when the expected class is absent. Do not create duplicate submissions to reconstruct missing history.

## Participate in live learning

The Trainer launches the current activity. Read the question, constraints, time and instructions. Respond through the matching control: select one or several choices, write text, enter a number, rate, rank, allocate points, match, sort, label/place on an image, draw, interact with video checkpoints or use the specified submission control. Use the shown options; do not assume every question accepts a free-text answer. Word Cloud may accept several words/phrases within length limits. Q&A and Ideas Board can require moderation; a saved item may remain hidden until approved. Voting and identity visibility depend on activity settings.

Submit once, wait for the actual saved confirmation and inspect your saved answer when supported. Before the Trainer reveals, the application confirms persistence without showing your score/correctness. Do not infer an answer from temporary ordering or other participants. Matching choices are intentionally separated from the correct associations. After reveal, read the permitted results/explanation and any personal feedback. Participation points do not automatically prove mastery.

For Team Challenge follow the assigned team instructions; the answer can be shared at team scope. For local file/image work, choose the intended file and check the saved submission. Do not upload executables, credentials or others' private data. Treat downloaded files as untrusted; a file download is not an instruction to run it. Link work must use a valid permitted URL. Video/checkpoint tasks depend on local media and browser codec support; ask for assistance if playback fails.

## Paths, missions and independent work

When offered a personal path, read the alternatives, choose the appropriate one and complete its steps. Follow the current milestone; do not assume all later work is open. Use the supplied prompts/resources as tools, not permission to send private data to an external AI service. External resources may need separate access and are not guaranteed offline. Submit the requested evidence, mark completion only when requirements are met and use Need help for Trainer support. If no submission is required, follow the explicit completion control. Read review feedback and revise when requested; opening a resource is not automatic completion.

In Participant-paced classes, use supported Previous/Next controls and keep saved work before moving. In Trainer-paced classes the live classroom follows the Trainer. In front-of-room delivery some scenes only ask you to observe. The Projector is a public display and does not expose your private profile or Trainer notes. Never put personal information in a response expected to be public.

## Saved work, feedback and profile

Use Saved responses to inspect any local pending queue. A queued response is not confirmed on the server until a successful retry. Keep the browser/device while resolving connectivity and check the current class/activity before retrying; do not assume every file submission is queued offline. Refresh/reconnect can restore persisted answers. If an activity has closed, ask the Trainer rather than forcing repeated retries. Do not clear browser storage during an unresolved queued response.

Open My profile to maintain your permitted contact/name/learning-goal details and photo. Some course/profile completion prompts require both Arabic/English names, email and mobile; enter accurate information only. Your contact information is restricted to yourself and authorized staff. Review communication/privacy consents; changing a preference retains consent history. Change your password through the provided form and keep it private. Administrators cannot safely receive your password in public messages.

Review learning history, class schedule/calendar, mission feedback, achievements/certificates and own learner reports where available. A certificate or progress indicator reflects recorded rules/evidence, not an external accreditation guarantee. If a report/download requires a current session, sign in again. Do not share report links containing credentials or private verification information. Ask the Trainer to correct missing attendance/review records; do not alter a downloaded report to make a false claim.

## Problems and safe departure

If you cannot join, confirm account, code, approval and capacity with the Trainer. If a response fails, read the error, check saved state/queue and retry only when appropriate. If the host is unavailable, keep your work and wait for reconnection; Internet access will not replace the classroom server. Expired sessions require sign-in. Unexpectedly visible private answers or another person's details should be reported immediately to the Trainer. Sign out on shared devices and close downloaded personal reports when finished.

## Current workspace repairs (RC1R10)

My profile → Change photo accepts validated PNG/JPEG up to 2 MiB. The saved picture appears in your account menu on return to the workspace. The main class/task loads before optional transcript/tools/inbox data; those sections can finish afterward. Loading still depends on the host and LAN.

To request admission, sign in with a registered participant account, choose Join class, enter the class code and wait for approval. Pending is not enrollment. Your assigned managing Trainer or Admin approves/declines subject to capacity/prerequisites. Check the request status and bell notifications. Read messages from the bell; Students do not send staff announcements. A role/group/team message reaches the recipients selected when it was sent.

My profile → Learning history lists your team under each class, including member names. Ask an authorized Trainer to move you or correct a team. A reusable group is different from a classroom team. The Trainer records Present/Late/Absent/Excused/Left early for a specific session; being online does not automatically record attendance. Ask for a correction when necessary; Not recorded differs from Absent.

The Trainer can move a live Projector pointer and add colored handwriting/text. These are presentation aids, not Student response submissions or automatic grading. They persist until the Trainer clears them. Continue submitting your own task through its activity control.

Your profile provides your authorized learner PDF report. Choose its language/dates, preview then download and protect it as private data. Installation-wide analytics and export choices belong to authorized staff. Check the current class, response acknowledgement and personal history when troubleshooting; do not treat a visible page as proof that a write saved.
