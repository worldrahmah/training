# RC1R7 known limitations and enterprise readiness boundaries

RC1R7 is a substantial experience/operational upgrade and owner-acceptance candidate. It is not a claim that ONE is the world's highest-ranked design or that every enterprise/school capability is complete.

- Verification runs on Linux, Node 24 and Chromium. Windows launch/shutdown, firewall/LAN devices, projector-room readability, screen readers and classroom hardware require owner acceptance.
- Browser checks cover every current Admin/ordinary-Trainer navigation view, entry screens and representative Builder/Participant/Live/Preview interactions in EN/AR, appearance and viewport variants. Inherited 36-activity/68-result certification remains automated evidence, not exhaustive visual/assistive-technology certification of every activity/setting/dialog.
- Solid-background text contrast checks use the WCAG relative-luminance thresholds. Complex gradients/images and other accessibility criteria still require visual/manual evaluation; passing these checks is not a full WCAG certification.
- Restore now has staged swaps and process-interruption recovery. It does not establish every hardware power-loss/storage durability guarantee. Existing schema migrations still lack a full ordered migration journal.
- The app remains one local-first Node/SQLite deployment without organization/tenant isolation. The 20-participant API rehearsal is retained; sustained large-scale or multi-site enterprise capacity is not certified. SSO/MFA/directory integration and deployment-specific hardening remain a separate product program.
- Bootstrap/demo provisioning remains. The `TRAINER` bootstrap account is a super administrator. Secure or disable demo/default accounts before organizational use. Required-password onboarding is available; a complete organizational provisioning wizard is still outstanding.
- Participant content Preview is explicitly a content preview. Full response interaction needs a real rehearsal class. Builder activity-specific preview, more visual configuration editors, media/PPTX fidelity and comprehensive tours remain further product work.
- Offline queue replay now preserves ownership/rejections and common in-progress response fields/drawings. Complex file-selection/media playback recovery and legacy unowned queue attribution remain limited. Legacy entries are retained; they are not silently replayed under another identity.
- Course visibility/permissions are substantially strengthened, but the source-ledger still distinguishes inspected paths from indexed or partially reviewed ones. An independent exhaustive authorization/transaction/performance audit remains an enterprise release gate.
- Historical external authoring v1.3 remains historical. The in-tree contract is synchronized with the current registry; the final regenerated external AI Course Creator kit follows the final Core freeze.
- School age/jurisdiction, safeguarding, academic model, guardian portal and integration/deployment scope remain owner architecture decisions. No school-domain schema or unsupported capabilities were invented in this candidate.

The package includes actual source, guides, test evidence and a feature-review ledger. Pending items are documented rather than represented by fake-success UI or unsupported certification claims.
