# Training Engine ONE Stage 1C Brainstorm / Ideas Board v3.4.0 RC3 — Engineering Summary

ONE preserves the professional RC4/Stage-0 lineage and accepted Stage 1A Word Cloud behavior while retaining v2.1.1/Codex compatibility. Stage 1B professional moderated/upvoted Q&A is owner-accepted. Stage 1C adds a professional Brainstorm / Ideas Board through the same canonical contract rather than creating a parallel interaction stack.

Key inherited and Stage-0 closures include:
- canonical activity/component registry plus mechanical drift gate;
- shared real-Projector/Builder-preview renderer and Projector theme tokens;
- Projector Dark / Light / High Contrast with Course → Class → temporary Live precedence;
- canonical version identity;
- professional security/session policy;
- failed-login throttling;
- temporary-password enforcement;
- concurrent-session limits;
- multiple simultaneous live classes;
- class join codes and self-enrollment policy;
- class-scoped Projector pairing;
- live Projector health auto-refresh in Trainer Live without page reload;
- dedicated Live Classroom console;
- hierarchical collapsible Course Flow;
- strict explicit-workflow graph validation and simulation;
- Left Early attendance + notes;
- append-only consent history;
- trainer submission review and participant feedback;
- participant schedule + calendar export;
- optimistic concurrency for mutable participant/authoring state;
- Builder autosave, Undo/Redo, revision history, compare/restore;
- Builder readiness/simulation, safe asset library and reusable templates;
- global search + saved views;
- audited bulk administration;
- configurable verified backups;
- course-improvement analytics;
- populated v2.1.1 → ONE migration regression coverage;
- explicit role-specific UI contract.

## Stage 1A Word Cloud
Word Cloud now exercises the complete canonical interaction path: registry → schemas/capabilities → Builder → validator → Participant → persisted response envelope → moderation/privacy → aggregation → shared result renderer/Projector → reports → restart/backup-restore → EN/AR → dedicated + full regression tests.

## Stage 1B Moderated / Upvoted Q&A
Q&A exercises the complete interaction path: registry → schemas/capabilities → Builder → validator → Participant question envelope/upvotes → Trainer moderation/facilitation → aggregation → shared result renderer/Projector → sanitized result recall → reports/privacy → restart/backup-restore → EN/AR → dedicated + full regression tests. Team response scope is deliberately rejected until team-voting semantics are designed rather than guessed.


## Stage 1C Brainstorm / Ideas Board
- Canonical `ideas_board` activity with `idea_board` response model and `ideas_board` aggregation/result renderer.
- Authored categories/columns with bounded participant idea submission and retry de-duplication.
- Optional pre-moderation and `public` / `trainer_only` / `anonymous` identity modes.
- Participant upvoting with configurable self-vote policy and votes/newest ordering.
- Trainer Highlight and non-destructive Merge/Unmerge; merged-source votes roll into the target while the source remains auditable.
- Audience hide-before-reveal, professional categorized Projector rendering, participation counts and Results History recall.
- Restart persistence, backup/restore continuity, anonymous report redaction, EN/AR and dedicated regression coverage.
- Team response scope intentionally fails closed until team-voting semantics are designed.
