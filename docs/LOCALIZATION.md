# Localization, RTL and Typography — v2.0

Training Engine supports complete English LTR and Arabic RTL system UI. Course-content language remains independent from application language.

Typography is configurable independently for:
- UI font;
- Presentation/Projector font;
- Title/headline font;
- Body/description font;

Each has Arabic and English values. Course branding may safely override these font families. Arbitrary CSS is not accepted from course packages.
