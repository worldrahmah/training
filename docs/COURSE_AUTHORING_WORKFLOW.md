# Course Authoring Workflow v2.0

1. Define course audience, outcome, language, duration and delivery constraints.
2. Use `authoring-kit/prompts/01_COURSE_ARCHITECT_PROMPT.md`.
3. Review/approve modules, objectives, walkthroughs, missions and activity flow.
4. Use `02_COURSE_PACKAGE_BUILDER_PROMPT.md` with the Component Catalog and schemas.
5. Use `03_INDEPENDENT_COURSE_REVIEWER_PROMPT.md` in a fresh AI chat or independent review pass.
6. Run `VALIDATE_COURSE.bat`.
7. Import only after zero blocking errors.
8. Preview Trainer / Projector / Participant interpretations.
9. Create/import a class using the class template/prompt.
10. Import/assign roster and trainers.
11. Rehearse the complete course before live delivery.

If a desired interaction is not present in `COMPONENT_CATALOG.md`, do not invent a JSON type. Treat it as a Core-extension request before authoring the course around it.
