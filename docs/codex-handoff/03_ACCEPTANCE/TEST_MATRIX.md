# Minimum test matrix

## Viewports
320x568, 375x667, 430x932, 768x1024, 1024x768, 1366x768, 1920x1080, at least one ultrawide/large presentation viewport.

## Locales/themes
English LTR + Arabic RTL; light + dark; System preference where supported.

## Roles
Super Admin, Lead Trainer, Assistant Trainer/limited Trainer, Participant, anonymous/projector where applicable.

## Course fixture scenarios
1. Legacy workflow-less linear module.
2. Explicit class-level branch (poll winner -> trainer demo path).
3. Participant independent branch with at least 3 paths and convergence.
4. Multi-step mission with prompt/image/external link/submission/offline fallback.
5. Team activity.
6. Existing immutable published version -> derive Draft -> edit -> validate -> preview -> publish.
7. Imported course -> edit via visual builder -> new Draft/version.

## Class scenario
Create course/version -> create class -> assign lead/assistant -> import 20 participants -> create 5 teams -> attendance -> live session -> vote -> branch -> guided practice -> help requests -> finish -> report -> backup -> restart -> restore.
