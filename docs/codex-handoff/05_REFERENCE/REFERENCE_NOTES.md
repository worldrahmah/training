# Owner-observed UI/workflow references

The included screenshots are historical evidence of defects discovered during iterative owner testing:
- `projector_before_fix.png`: Projector looked like a webpage with poor composition rather than a presentation stage.
- `workflow_explicit_issue.png`: Explicit workflow could remain Current after Finish when transitions/course authoring were incomplete.
- `workflow_completed_group.png`: Linear workflow status progressed correctly, but showed why groups need hierarchical collapse to avoid endless scrolling in real courses.

Do not reproduce these exact screenshots as design targets; use them to understand defects that must not recur.
