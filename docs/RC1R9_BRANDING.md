# Shared logo / الشعار الموحد

Admin → Settings → Company branding → Upload company logo. Choose a PNG or JPEG up to 2 MB and 4096 × 4096 pixels; the server decodes/checks media and rejects active content. Save company name/contact/footer separately. The same uploaded logo is returned by /api/system-logo for sign-in and all shared application surfaces, including Admin, Trainer, Student, Course Editor, Builder, Profile, Preview, Live Classroom, Certificate and Projector. Professional reports keep the same branding; a previously reviewed PDF snapshot preserves its original logo by design. Reload an open page to see a replacement. Remove logo restores the bundled Training Engine mark. No source edits, Internet font service or database edits are needed.

The logo is intentionally public to unauthenticated sign-in visitors; do not put private information in the image. Only authorized administrators may change it. It lives under configured storage/branding and is included with existing verified backup/restore. The endpoint exposes only the validated logo, not private settings, contact records or paths. PNG with readable transparent/light background and a square canvas is recommended; check light/dark, mobile and 16:9 Projector with your actual mark. Retain its usage rights. Do not edit generated source branding files for a routine owner replacement.

من حساب المسؤول افتح الإعدادات ثم الهوية المؤسسية وارفع PNG أو JPEG ضمن الحدين المذكورين. يطبق الشعار نفسه على الدخول ومساحات العمل والعرض والتقارير دون تعديل المصدر. أعد تحميل الصفحة المفتوحة لرؤية الاستبدال. إزالة الشعار تعيد العلامة المضمنة. تحفظ التقارير المراجعة سابقًا شعار اللقطة، وتُنسخ أصول الهوية مع التخزين في النسخ الاحتياطية. الشعار عام عمدًا؛ لا تضع فيه بيانات خاصة. اختبر وضوحه في العربية والإنجليزية والمظهرين والهاتف وشاشة القاعة.
