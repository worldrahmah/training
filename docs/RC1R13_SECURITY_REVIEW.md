# RC1R13 security and operational review

New Trash actions authenticate first, enforce class/course deletion scope, separate Archive, retain snapshots for exact lifecycle restore and reject active-class deletion. Permanent deletion requires administrator scope, an already trashed object and exact-name confirmation. Referenced course versions block course purge. Existing SQLite cascades perform deletion atomically; permission grants, stale report snapshots, linked notifications and owned submission/asset files are removed. Audit survives. No real owner purge is performed during development; all tests use disposable state.

Every relevant direct write is checked before mutation and again after awaited body upload, so delayed draft/course/file requests cannot write into newly trashed records. Unauthenticated callers retain 401 and unauthorized roles 403. Archive restore cannot bypass Trash. Parent course references in class creation/import are checked. Search, counts and learner survey/quiz actions honor Trash. Direct classroom projection authenticates enrollment and returns only the explicitly requested class; no fallback leaks or switches another running class. Canonical Participant sanitization, private Trainer cues and score/reveal rules are retained.

Workspace loading does not cache API data across accounts or weaken permissions. It loads datasets on the view that needs them, discards responses from obsolete view generations and coalesces refreshes without dropping a pending final update. Passive toasts cannot block controls. Builder starter is declarative canonical data, shares the validator/runtime and introduces no executable course package content. Course language for generated lesson labels is independent of UI language.

Existing authentication, default-account policies, sessions, RBAC, package/ZIP paths/checksums, safe Markdown, uploads, backup/restore and LAN assumptions remain. This review is supported by tests, not a formal penetration certification. Owner Windows/LAN/actual assistive-technology acceptance remains separate.
