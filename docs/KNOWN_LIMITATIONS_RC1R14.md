# RC1R14 acceptance boundaries

No known failing mandatory engineering gate may ship. Owner Windows/LAN/classroom/visual/actual assistive acceptance remains manual; the candidate is not automatically FINAL. External tools need their own connection; uploads/fresh loads/confirmed navigation require the local server. Pending personal choices remain locally until that account reconnects; another device receives them after server confirmation. Color/theme changes may appear immediately in another same-account tab, while a language change in an already open other tab is applied on reload to avoid replacing unsaved work.

Finish is an authorized, confirmed end of the class; it preserves partial records rather than completing unfinished learner tasks. Deliberate activation can reopen it. Trash restore and administrator-confirmed purge retain their dependency/impact rules. Activity history contains recorded operations, not unrecorded user behavior. Offset pages are deterministic per query; new records arriving between requests can shift later offsets, so Refresh resets to the current view. Date filters use the viewing device's local calendar.

Cloud draft persistence does not publish a snapshot or establish independent fresh-task restoration. No universal bug-free/security/assistive certification is claimed.
