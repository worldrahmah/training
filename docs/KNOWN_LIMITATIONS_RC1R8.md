# RC1R8 known limitations and acceptance boundary

- This is an owner-acceptance candidate for the approved training-center workspace milestone. Windows installation, copied real-data upgrade and physical classroom/Projector rehearsal require owner acceptance. No evidence supports “number one in the world,” “2050-certified,” or whole-platform FINAL.
- One local organization per installation. School terms/timetable/gradebook/guardian/safeguarding and multi-tenant operation are not implemented in this milestone. Existing platform-wide future gaps in the prior architecture/research documents remain open.
- The existing bootstrap/demo provisioning remains; secure it before organizational use. SSO/MFA and external identity services are not newly introduced. Bundled runtime does not imply external security accreditation.
- Forty bundled font families and responsive representative role tests pass. Not every possible authored string, font weight, browser or projected-device combination is manually accepted. Static families use their supplied normal weight; browsers may synthesize heavier weights. Global selection deliberately takes precedence over legacy per-course typography.
- Response/event date filters use stored UTC dates; attendance uses the authored session date. PDF reports use recorded evidence, not arbitrary BI or normalized grades. Dataset limits are 10,000 records; use narrower dates/class scope. Two exports can run concurrently; a worker stops after 45 seconds with a truthful retry/smaller-scope message. Existing charts/CSV exports remain available. PDFs are snapshots, not continuously updated documents.
- PDF exports include embedded fonts and logical ActualText spans for shaped Arabic/mixed text; this is not a claim of PDF/UA certification. Long table rows split across pages. JPEG headers/dimensions/terminator and PNG checksum/decompression structure are checked; raster formats other than PNG/JPEG are unsupported for profile/company images.
- New registered-account admission always requires approval. Old join-policy/guest-setting fields remain as backward-compatible stored history; they do not authorize new anonymous joining or bypass approval. Historical guest sessions/enrollments remain usable. Staff group application skips Course Editors and does not replace the class lead.
- Preview tokens expire after five minutes; report previews expire after one hour. Saved accepted PDF exports persist in backed-up storage. There is no new automatic retention policy for saved personal reports; operational retention choices remain the organization's responsibility.
- Downgrading in place is unsupported after new Editor/admission data is used. Rollback uses the verified pre-upgrade database-plus-storage backup and the previous application. Changes after that snapshot require a newer compatible release or a separately designed migration; never manually edit the database.
- Existing single-process synchronous SQLite remains the local-first foundation. Representative concurrent classroom/reconnect/load regression is retained; this release does not establish an unlimited-capacity service guarantee.
