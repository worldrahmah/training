# Guided intake / الاستبيان الموجّه

Use `node tools/intake-wizard.mjs new-intake-directory`. For repeatable intake use `--answers answers.json` with every named answer below as a nonempty string. The wizard saves intake.json and NEXT.md and refuses to overwrite an existing directory; it does not pretend to generate a complete course. No credentials are requested.

| Answer key | Discuss with owner / ناقش مع صاحب الدورة |
|---|---|
| title | Subject, course title and intended change / الموضوع وعنوان الدورة والتغيير المقصود |
| language | en or ar; course direction and bilingual needs / اللغة واتجاه المحتوى واحتياجات الثنائية |
| audience | Prior knowledge, prerequisites, roles, access needs / المعارف السابقة والأدوار ومتطلبات الإتاحة |
| objectives | Observable outcomes, evidence and acceptance criteria / النتائج القابلة للملاحظة وأدلتها ومعايير قبولها |
| timing | Duration, class size, milestone count, breaks and debrief / المدة وحجم الصف وعدد المحطات والاستراحات والنقاش |
| delivery | Trainer-paced, participant-paced or front-of-room; device/LAN constraints / نمط التقديم والأجهزة والشبكة |
| assessment | Diagnostic/formative/summative intent, scoring and reveal timing / غرض التقييم والنقاط وتوقيت الكشف |
| assets | Local owned/licensed images/video/files, accessibility and offline availability / الأصول وحقوقها وبدائلها وإتاحتها محليًا |
| privacy | Trainer-only guidance, anonymous/public identity choices and data minimization / إرشادات المدرب وهوية المشاركات وتقليل البيانات |
| milestones | Proposed milestone titles and sequencing / المحطات المقترحة وتسلسلها |
| first_milestone | Exactly ONE milestone authorized for current work / محطة واحدة فقط مصرح بكتابتها الآن |

Before drafting, return a brief mapping objectives to evidence, timing, supported components and role surfaces. Identify missing facts, explicit assumptions and CORE CAPABILITY GAP items. Ask only material questions; do not expand to later milestones without permission. Acceptance record: approved outline, accepted milestone ID, accepted activity/path/node IDs, version, evidence and remaining uncertainties. Do not change these IDs in later revisions.
