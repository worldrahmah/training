# Users, Roles and Permissions — v2.0

## Super Admin

Global authority for system administration, staff, courses, versions, classes, participants, settings, reports and read-only monitoring of live classrooms. Super Admin may grant scoped permissions to Trainers.

## Administrator

Administrative authority without the protected Super Admin promotion authority where restricted by policy.

## Trainer / Assistant Trainer

Access is determined by assigned classes plus explicit resource grants. Course creation/edit/delete/publish, class creation/manage and participant administration can be scoped independently.

## Participants

Participant identity includes an immutable username/ID and a richer editable profile. Profile completion can require Arabic full name, English full name, email and mobile number. Optional WhatsApp, Telegram, organization, specialty, job title, city, country, goals and communication-consent fields are supported.

Participants can change their password, update permitted profile fields, manage consent preferences and sign out.
