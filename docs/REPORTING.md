# Reports and Learning Analytics — v2.0

The Reports/Analytics layer supports platform-, course-, course-version-, class-, trainer-, participant-, activity-, objective-, path-, help-, attendance- and completion-level analysis.

Available analytics include:
- high-level KPIs;
- attendance distribution;
- completion by class;
- course-version comparison;
- participant-path selection;
- objective performance;
- Help Queue status and hotspots;
- class activity and participation;
- existing scoped historical reports and CSV exports.

Super Admin receives global scope. Trainers receive only authorized scope.
