# Demonstration asset provenance / مصدر أصول العرض

assets/video.mp4 is a synthetic three-second silent H.264 color scene generated locally with FFmpeg for this kit. assets/map.png is the repository synthetic report-logo test fixture, not a claim to the owner’s identity. These sample assets contain no personal data. Replace them with owned/licensed instructional assets and supply rights, alternative text, transcripts/captions, dimensions, duration and file hashes for real courses. The package manifests and kit SHA256SUMS verify the supplied bytes.
